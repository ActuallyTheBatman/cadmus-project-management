California Connect EPC — Key Staff Project Manager

In Evaluation

Cadmus is proposed as the named Key Staff Project Manager on Communication Service for the Deaf's (CSD) proposal for the California Connect Equipment Processing Center (EPC) contract, supporting the distribution and lifecycle management of specialized telecommunications and assistive equipment for Californians with disabilities.

  • Role: Project Manager, Key Staff — PMBOK-aligned project management plans, deliverable oversight, risk and issue management, and stakeholder coordination
  • Term: Initial one-year term with extension options
  • DVBE participation submitted per RFP requirements, including signed DVBE Declaration and SDVOSB certification
Prime: Communication Service for the Deaf Program: California Connect / CPUC Role: DVBE Key Staff PM

Covered California Information Security Services — DVBE PMO Support

In Evaluation

Cadmus is partnered with Anvaya Solutions as a DVBE subcontractor providing project and contract management support for information security services delivered under a Covered California contract.

  • Scope: Project coordination, delivery governance, schedule and milestone tracking, risk and issue management, status reporting, and PMO documentation
  • Structure: Defined commercially useful function (CUF) tied to project and contract management, consistent with DVBE incentive requirements
Prime: Anvaya Solutions Agency: Covered California Role: DVBE CUF — PMO Support
